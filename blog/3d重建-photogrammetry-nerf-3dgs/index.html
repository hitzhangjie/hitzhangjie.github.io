3D 重建技术演进：从摄影测量到 3D Gaussian Splatting

Posted 2025-11-27 00:00 +0800 by ZhangJie ‐ 2 min read

分享:  

背景 #

3D 重建——从多张二维照片还原出三维场景——是计算机视觉领域的核心问题之一。无论是游戏资产制作、高精地图测绘、数字孪生，还是最近火热的空间计算，都离不开这项技术。

过去二十年，3D 重建的技术路线发生了巨大变化：从基于几何原理的传统摄影测量，到 2020 年横空出世的 NeRF 神经辐射场，再到 2023 年席卷学界的 3D Gaussian Splatting。本文梳理这条技术演进脉络，帮助读者理解不同方案的核心思想、优劣和适用场景。

传统方法：摄影测量（Photogrammetry） #

传统摄影测量的核心流程可以概括为两步：运动恢复结构（Structure from Motion, SfM）和多视图立体匹配（Multi-View Stereo, MVS）。

SfM（稀疏重建）：从多张不同角度拍摄的照片中，分析相机的位置和姿态，同时生成稀疏的三维点云。这一步解决了"每张照片是从哪里拍的"这个问题。

MVS（稠密重建）：在已知相机参数的基础上，对场景进行像素级别的深度估计，生成稠密点云或三角网格模型（Mesh）。

开源工具：Colmap 与 Meshroom ##

Colmap 和 Meshroom 是这一领域最具代表性的开源软件。Colmap 更偏学术，提供完整的 SfM + MVS 管线，命令行友好；Meshroom 基于 AliceVision 框架，提供可视化节点编辑器，更适合艺术家和设计师使用。

这两者过时了吗？ 并没有。它们在需要精确几何网格的场景中仍然是首选——比如测绘、建筑信息建模（BIM）、游戏资产生成。但它们的局限也很明显：

  • 对光照变化、无纹理表面（白墙）、重复纹理（瓷砖地面）非常敏感，容易产生空洞或错误匹配；
  • 难以处理动态物体，要求拍摄过程中场景完全静止；
  • 计算过程通常非常耗时，大场景可能需要数小时甚至数天。

辅助工具：MeshLab ##

MeshLab 是点云和网格模型的后处理利器。Colmap 输出的 .ply 点云文件通常带有大量噪点和离群点，需要在 MeshLab 中进行清理、简化、补洞、重网格化等操作。它也常用于格式转换和可视化预览。

商业方案：RealityScan 与 Metashape ##

Epic Games 的 RealityScan 和 Agisoft 的 Metashape 是商业化摄影测量软件的代表。它们将拍照、对齐、重建、纹理映射集成为一站式流程，在易用性和重建质量上做了大量工程优化，但底层原理与 Colmap/Meshroom 并无本质区别。

神经渲染的崛起：NeRF #

2020 年，NeRF（Neural Radiance Fields）的出现彻底改变了 3D 重建的游戏规则。

核心思想 ##

NeRF 不再生成显式的网格或点云，而是用一个神经网络来表示场景——输入一个空间坐标 (x, y, z) 和观察方向 (θ, φ)，网络输出该点的颜色和密度。通过体渲染（volume rendering）沿光线积分，就可以合成任意新视角的图像。

换句话说，NeRF 学到的不是一个 3D 模型，而是一个能渲染出任意视角照片的渲染函数。这种表示被称为"隐式表示"（implicit representation）。

优势与局限 ##

NeRF 对复杂光照、反射、半透明材质的还原效果远超传统方法，细节表现力极强。但问题也很致命：

  • 训练慢：单个场景需要训练数小时到数天；
  • 渲染慢：生成一张新视角图像需要几秒到几十秒，远达不到实时；
  • 不可编辑：隐式表示无法直接导入传统 3D 软件进行编辑。

NeRF 是革命性的——它证明了用神经网络隐式表示场景这条路走得通。但速度瓶颈让它很难走出实验室。

新的范式：3D Gaussian Splatting（3DGS） #

2023 年，3D Gaussian Splatting（3DGS）横空出世，在保持 NeRF 级渲染质量的同时，实现了实时渲染。

核心思想 ##

3DGS 用显式的三维高斯球（3D Gaussian primitives）来表示场景。每个高斯球都有位置、协方差（形状）、颜色（球谐函数）和透明度（alpha）等参数。场景被表示为几万到几百万个这样的"带颜色的半透明椭球体"。

渲染时，将这些高斯球按深度排序后投影到图像平面，通过 alpha blending 合成最终图像。整个过程高度可并行，天然适合 GPU 光栅化管线——这就是它能实现实时渲染的根本原因。

与 NeRF 和传统方法的对比 ##

维度传统摄影测量NeRF3DGS
场景表示网格/点云（显式）神经网络（隐式）高斯球集合（显式）
训练时间分钟~小时（SfM+MVS）小时~天分钟~小时
渲染速度实时秒级/帧实时（>30 FPS）
几何精度高中中~高

3DGS 巧妙地取了二者的长处：NeRF 的高质量视角合成能力 + 传统显式表示的渲染效率和可编辑性。

技术发展脉络总览 #

回顾整个 3D 重建技术的发展历程，可以清晰地看到三个阶段：

  1. 传统摄影测量时代（2000s~至今）

    • 代表：Colmap、Meshroom、Metashape
    • 产物：网格（Mesh）/ 点云
    • 成熟稳定，在测绘、工程等领域广泛应用

  2. 神经辐射场时代（2020~2023）

    • 代表：NeRF 及其变体（Instant NGP、Mip-NeRF 等）
    • 产物：隐式神经场景表示
    • 革命性地证明了神经渲染的可行性，但速度是硬伤

  3. 显式神经表示时代（2023~至今）

    • 代表：3D Gaussian Splatting
    • 产物：大量三维高斯球集合
    • 解决了速度瓶颈，实现高质量实时渲染，目前最前沿

未来方向 #

3D 重建远没有到终点，以下几个方向正在被学术界和工业界积极推进：

  • 动态场景重建（4D）：对运动的人或物体进行实时 4D 建模，这在体育转播、影视特效中有直接需求。
  • 可编辑性：如何方便地编辑 3DGS 场景——移动、删除、修改单个物体——是一个活跃的研究课题。
  • 大规模场景：从桌面小物体到城市级别超大规模重建，内存和计算效率仍然是挑战。
  • 端侧实时重建：在手机等移动设备上实现边拍边建，苹果和谷歌已在 Vision Pro / ARCore 中探索相关技术。

商业应用 #

高德的高精地图、大疆的无人机测绘、其域创新的数字孪生和文旅——这些公司业务的核心都是大规模、高精度的三维空间数字化。从传统摄影测量到 3DGS，每代技术的迭代都在降低重建成本、提升效率和效果，这些公司将是最直接的受益者。

总结 #

3D 重建技术正处于一个非常有意思的转折点。传统摄影测量依然是精确几何重建的可靠选择，NeRF 打开了神经渲染的大门，而 3DGS 则让高质量实时渲染变得触手可及。

理解这三条技术路线的核心思想和适用边界，才能在实际项目中做出正确的技术选型。如果你刚开始接触这个领域，建议的顺序是：先用 Colmap 跑一遍传统管线理解基本原理，再用在线 demo 体验 NeRF 的视角合成效果，最后上手 3DGS 感受实时渲染的魅力。
